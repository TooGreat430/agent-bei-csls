# Konteks klien & ekspektasi (PTPL — tim MIR)

- User akhir non-IT: hasil harus file siap pakai (Excel, PDF, PPTX, Word), bahasa Indonesia, angka format Indonesia.
- User utama sangat terbiasa dengan aplikasi Claude; PTPL membeli Gemini Enterprise. Penjelasan yang disepakati:
  "Claude seperti analis yang membawa laptop sendiri; GE seperti analis dengan akses ke seluruh sistem kantor. Lewat
  agent ini, analis GE PTPL dibekali 'laptop' itu" — jangan menyebut "Claude hanya otak" atau "Gemini lebih bodoh".
- Requirement terkini: Claude untuk tugas berat (sudah), kemampuan seperti aplikasi Claude (skill file, melihat gambar),
  insight multi-chart otomatis dan teknik analisis pptx "Overnight Strategist – Strategist Toolkit V3".
- Data region: Claude & Flash diproses di global (tidak ada lokasi Claude di Asia); PTPL sudah menyetujui Claude.
- Batasan yang perlu dikomunikasikan: chart dibuka via link (GE belum menampilkan gambar dari agent ADK); jalur upload
  file lebih kuat untuk analisis mendalam (Claude + data mentah) dibanding jalur BigQuery (Flash + data agregat).
- Contoh kasus uji yang dipakai klien: Mesrania 2T price competitiveness (file pivot), RFM SR1 (53.310 baris,
  5.918 outlet), gap harga Product Hero per SR Q3 2026, laporan dari gambar contoh (kelompok per PTPL product name).
