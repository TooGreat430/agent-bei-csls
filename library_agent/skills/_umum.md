Aturan file:
- Simpan file di direktori kerja dengan nama jelas tanpa spasi (mis. Analisa_RFM_SR1_2025.xlsx).
- JANGAN menyimpan hasil akhir sebagai .txt/.md (tidak akan dikirim ke user).
- Mengedit file milik user: simpan sebagai file BARU dengan akhiran _revisi (mis. Laporan_Q3_revisi.pptx); nama yang
  sama dengan file masukan tidak dikirim.
- Setelah membuat file, buka lagi dengan library yang sama dan cetak ringkasan isinya (jumlah sheet/slide/halaman,
  judul, beberapa angka kunci) untuk memastikan file benar sebelum dilaporkan ke user.
- Semua angka di file berasal dari perhitungan kode di sandbox, bukan diketik dari kepala.
- Aturan bisnis PTPL tetap berlaku: bandingkan harga per liter bila kemasan berbeda; KIMAP untuk head-to-head;
  carry/outlet = exposure, bukan market share; survei = asosiasi, bukan sebab-akibat.
